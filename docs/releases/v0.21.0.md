# v0.21.0

## 新增

- 新增 OpenClip 扩展：在 OpenClip 中选择 **MoePeek**，将选中文字交给 MoePeek 翻译，沿用已配置的翻译服务和目标语言。扩展包 `MoePeek.openclipext.zip` 随 Release 提供。([#113](https://github.com/cosZone/MoePeek/issues/113))

## 发布验证

- 新增 PR / main 分支的完整测试工作流，无需发布签名凭据即可运行。
- 发布前运行完整 `MoePeekTests`，测试失败时停止后续打包与发布；测试报告作为 Actions artifact 保留 14 天。
- 为外部 URL 翻译入口增加集成覆盖，验证中文、表情、换行、URL 特殊字符及无效请求的处理。
